# Runway Management System

A C# console application built on .NET 10 to manage airport runway allocations, sequence landing and takeoff queues, and streamline aircraft traffic operations.

## Features
- **Queue Management:** Organize inbound arrivals and outbound departures efficiently.
- **Runway Allocation:** Monitor runway status to coordinate takeoffs and landings without conflict.
- **Modern .NET 10 Platform:** Built targeting .NET 10 for low-latency, lightweight execution.

## Tech Stack
- **Language:** C#
- **Platform:** .NET 10.0
- **Project Type:** Console Application
